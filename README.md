# AIRPP — AI Record Provenance Protocol

Open, vendor-neutral standard for verifiable AI-assisted records.

→ Live site: https://airp-protocol.github.io/airpp-registry/
→ Validator: https://airp-protocol.github.io/airpp-registry/validator.html

---

## What is AIRPP?

AIRPP defines how AI-generated or AI-assisted work can be:
- Proven
- Audited
- Verified
- Trusted across systems

---

## Try it now

Paste a manifest into the validator:
https://airp-protocol.github.io/airpp-registry/validator.html

---

## Why this exists

AI outputs are currently:
- Untraceable
- Unverifiable
- Easy to manipulate

AIRPP fixes that.
